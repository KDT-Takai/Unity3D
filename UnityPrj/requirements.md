# BallCollect — 仕様

球を転がして床の上のアイテム5個を回収するゲーム。シーン: `Assets/Scenes/BallCollect.unity`

## 基本仕様（完成条件）

| ID | 条件 |
|----|------|
| B1 初期状態 | 床・球(Player)・固定カメラ・アイテム5個がある。回収数0（`0/5`）、CLEARは非表示 |
| B2 移動 | WASDで移動。W=+Z、S=−Z、D=+X、A=−X。カメラは方向が分かる固定視点 |
| B3 回収 | 触れたアイテムが消え、回収数が1増える。同じアイテムで二重加算しない |
| B4 クリア | 5個すべて回収したときだけCLEARを表示。回収途中では表示しない |
| B5 落下 | 床から落ちたら、位置・速度・回収数・アイテム・UIをすべて初期化（位置だけ戻す実装にしない） |
| B6 Rで再開 | 途中でもクリア後でもB1と同じ初期状態へ。入力はInput Systemで統一 |

## 追加ルール：30秒の時間制限（目的：回収順に意味を持たせる）

| ID | 条件 |
|----|------|
| A1 | 残り時間を表示し、プレイ中に減る（`TimerText`、右上） |
| A2 | 未回収のまま0でTIME UP、移動停止 |
| A3 | 時間内の全回収でCLEAR、時計は停止 |
| A4 | CLEAR後に時間切れへ変わらない |
| A5 | Rと落下で残り時間も30秒に戻る。TIME UP後もRは効く |

優先順位: 同じ更新で5個目の回収と時間切れが重なる場合は回収完了を優先する。

## ホラー版（利用者の依頼で変更）

テーマ: 夜の呪われた島。亡霊から逃げながら5つの魂の灯を集め、灯台をともす。

### 追加ルール：亡霊
| ID | 条件 |
|----|------|
| H1 | 亡霊 `Ghost` が (0, 1, 9) から球を追う。速さ 2 m/s ＋ 回収1個ごとに +0.5 m/s（球は 5 m/s） |
| H2 | 水平距離 0.9 以内でつかまる：「つかまった…」表示、移動・時間・回収が止まる |
| H3 | 全回収で灯台が灯り、亡霊は消える（クリア後はつかまらない） |
| H4 | R・落下で亡霊も初期位置へ戻る |

### 見た目
| 要素 | 見た目 |
|------|--------|
| 環境 | 夜・霧、月明かり程度の暗さ、黒い背景 |
| 球 → ロボット | 懐中電灯で進む向きを照らす。背中のバッテリーと画面左上の5マスが回収数で青白く点灯 |
| 四角 → 魂の灯 | 青白く光る立方体（周囲を照らす）、浮遊・回転。島に散らして配置 |
| 亡霊 | 半透明の白い体に黒い目と口、ほのかに光る。球の方を向いて漂う |
| 周り | 暗い海、枯れ木と傾いた墓石の小島、岩 |
| 灯台 | 全回収でランプが灯り周囲を照らす |
| 画面下 | 「亡霊から逃げながら、5つの魂の灯を集めて灯台をともせ…」「WASD：移動　R：やり直し」 |

すべてUnity標準の形状（外部アセットなし）。装飾にはコライダーを付けない。生成は `BallCollect > Build Scenery`（`Assets/Editor/SceneryBuilder.cs`）。

## 調整値

| 項目 | 値 |
|------|----|
| 床 | 20×20（Plane, scale 2,1,2）、暗い草地 |
| 球 | 青、初期位置 (0, 0.5, −7)、Rigidbody |
| アイテム | 立方体(0.6)、Trigger。配置 (−6,−4) (6,−2) (−3,3) (7,6) (−7,8) |
| 移動速度 | 5 m/s（水平速度を直接設定） |
| 落下判定 | 球の Y < −3 |
| カメラ | 固定 (0, 16, −18)、俯角 45°（画面上が+Z） |

## CLIで読む状態

- `GameManager` コンポーネント: `collectedCount`, `isCleared`, `remainingTime`, `isTimeUp`, `isCaught`
- `Ghost` の位置と `CurrentSpeed`
- `Player` の Transform / Rigidbody
- アイテム `Item_1`〜`Item_5` の active 状態
- UI: `CountText`（`n/5`）、`ClearText`（CLEAR）、`TimerText`（`TIME n`）、`TimeUpText`（TIME UP）

## 範囲外

敵、外部アセット、効果音、複数ステージ、ランキング、オンライン機能、動画収録、実行ファイルのビルド。
